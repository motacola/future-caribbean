# Caribbean Opportunity Dispatch — Judge Demo Kit

Generated for a 3-minute live demo with rehearsed fallbacks.

---

## 1. The pitch in three sentences

Caribbean opportunity data is split across thirteen public sources, six countries’ portals, and a handful of old-style bulletins — so a deal or procurement window is often missed before it opens. Caribbean Opportunity Dispatch watches those sources on a four-hour cycle, grades the signals, pre-assembles the diligence evidence, and routes a clear next move to the right person. The desk is built so humans read it and any agent queries it: one HTTP API, one tool manifest, one MCP adapter, and the same deterministic engine behind all of them.

## 3. The agent demo (terminal, 30 seconds)

These are the three ways documented in the README to call the same engine.

**curl**

    curl -s -X POST https://abeng.vercel.app/api/ask \
      -H "Content-Type: application/json" \
      -d '{"question":"draft a note for Guyana"}'

Expected shape: `{"question": "...", "answer": "...", "engine": "deterministic", "generated_at": "..."}`.

**abengctl (local)**

    python3 cli/abengctl.py ask "what changed this cycle"

Expected shape: formatted answer plus **Sources:** line in terminal styling.

**HTTP tools / MCP client**

Point a tool-calling agent or MCP client at the hosted `/api/tools.json`:

    curl -s https://abeng.vercel.app/api/tools.json | python3 -m json.tool | head

**Claude MCP connect line**

Add this to your MCP config and restart Claude Code/Desktop:

    {
      "mcpServers": {
        "caribbean-desk": {
          "command": "python3",
          "args": ["mcp_adapter/desk_server.py"],
          "cwd": "/absolute/path/to/future-caribbean"
        }
      }
    }

Available tools: `desk_status`, `list_signals`, `get_dispatch`, `get_validation_pack`, `ask_desk`, `record_feedback`.

## 5. Failure drill

**Wi-Fi dies (or Vercel goes down)**
Run this from the repo root:

    node ./node_modules/astro/bin/astro.mjs build && python3 server.py

Then open `http://localhost:8080/`. server.py serves the built Astro desk plus the same JSON API locally, so the walkthrough works without the hosted deployment. For a no-API static fallback, `cd dist && python3 -m http.server 8090` and open `http://localhost:8090/`.

Ask-desk output shows the offline/empty-desk state. Say plainly: “The artifacts ARE the product; the site is just a window.”

**A judge asks: “Is this AI-generated content?”**
Honest answer: the pipeline is deterministic — it merges public records, normalizes them, and applies fixed scoring rules. The only LLM in the system is the agents that consume it. The `humanizer` is a translation layer, not a generator. Every answer in Ask and every feed item is cited from `outbox/*.json` or `outbox/*.md`.

**A judge asks about Jamaica tenders**
Honest answer: Jamaica GOJEP procurement is not exposed in the public instance — its public listing sits behind a session-gated portal (ePPS). Guyana eProcure (`eprocure.gov.gy`) is live and already in the validation pack. The system degrades honestly rather than fabricating country coverage.
